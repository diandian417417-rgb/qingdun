# moderation · 审核引擎模块

负责人：张圣喆（协同：唐思竹）｜对应项目计划书 4.3

## 文件结构

| 文件 | 作用 | 对应架构层 |
|---|---|---|
| `normalize.py` | 文本归一化：谐音/拼音/emoji/符号还原 | 第 1 层 |
| `rules.py` | 敏感词规则匹配 | 第 2 层 |
| `engine.py` | 审核入口 `review(text)`，返回风险等级和处置建议 | 汇总 |
| `words.txt` | 敏感词库（每行一个词） | 数据 |

## 本地验证

```bash
cd backend
python moderation/engine.py
```

能看到 5 条演示内容各自的审核结论即正常。
